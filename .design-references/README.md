# Design System References (`awesome-design-md`)

This directory contains 74 curated `DESIGN.md` design system specifications from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md). 

Each `DESIGN.md` file defines the exact **color tokens**, **typography scales**, **card and component styles**, **layout rules**, and **anti-patterns** extracted from world-class digital brands.

---

## How to Use with AI Agents

To adopt any design system in this project:

1. **Copy the desired `DESIGN.md` to your workspace root:**
   ```bash
   cp .design-references/linear.app/DESIGN.md ./DESIGN.md
   ```
2. **Direct your AI agent:**
   > *"Redesign the product catalog following the design system tokens and layout rules defined in DESIGN.md."*
